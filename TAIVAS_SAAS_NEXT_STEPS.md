# TAIVAS SaaS Next Steps

## Current status

TAIVAS is currently a structured Streamlit prototype with separated configuration, model, forecast, export, and render layers.

## Recommended next stages

### V7: User workflow polish

- Add clearer onboarding text
- Add a sample-data mode
- Add explanation panels for each tab
- Add demo vs analyst mode labels

### V8: Report mode

- Create a cleaner report-ready summary page
- Add risk score summary cards
- Add downloadable PDF or HTML report preparation

### V9: Data layer preparation

- Define standard uploaded history schema
- Add sample CSV template
- Add input validation warnings
- Add dataset version notes

### V10: SaaS backend planning

- Decide whether to keep Streamlit as frontend or move to React/API later
- Define account tiers: Demo / Pro / Enterprise
- Define audit logging requirements
- Define data privacy and retention policy

## Product positioning reminder

TAIVAS should be described as a decision-support simulator, not as a guarantee of real-world infrastructure performance.
