# TAIVAS Energy Control Center

TAIVAS is a Streamlit-based prototype for energy resilience simulation.

## Features
- Country and city selection
- Multilingual UI
- Weather simulation
- Energy demand vs supply charts
- Battery storage visualization
- Grid stability analysis
- AI recommendation panel

## Main file
`taivas_control_center.py`

## Run locally
```bash
pip install -r requirements.txt
streamlit run taivas_control_center.py
